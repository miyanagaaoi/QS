# 采购与项目管理平台 · 使用说明

> 本文面向**实际使用系统的人**（管理员 / 采购员 / 供货商），讲"每个页面怎么用、有哪些坑"。
> 部署、环境变量、备份、排障看 [DEPLOY-DOCKER.md](DEPLOY-DOCKER.md)；需求规则看 [PRD](PRD-询价报价系统.md)。

| 项 | 内容 |
|---|---|
| 适用版本 | **v1.0.0**（含 `CH-001`~`CH-010` 全部改动，2026-10-24） |
| 访问地址 | 本机演示：前端 `http://127.0.0.1:5173/`，后端 `http://127.0.0.1:8000/`（后端同时托管已构建页面） |
| 启动方式 | Windows 双击根目录 `start.bat`；停止用 `stop.bat`（详见部署手册 §2.0） |
| 两个模块 | **采购报价**（询价单 → 供货商报价 → 比价导出）与**项目管理**（多项目进度/工期/预算决算），两者数据互不关联 |

---

## 1. 登录与角色

| 角色 | 能看到什么 | 说明 |
|---|---|---|
| **管理员** `admin` | 采购管理 + 项目管理 + 系统管理（全部） | 可维护标准模板、删除项目/单据、管理账号与字典 |
| **采购员** `wangcaigou` | 采购管理 + 项目管理 | **看不到系统管理**；只能看到自己创建的询价单及其统计 |
| **供货商** `hengxin_wenju` 等 | 只有"待报价 / 已报价" | 不显示左侧菜单；只能看到发给自己的询价单 |

默认演示账号（`SEED_DEMO=1` 时创建）：

| 角色 | 账号 | 密码 |
|---|---|---|
| 管理员 | `admin` | `Admin@2026` |
| 采购员 | `wangcaigou` | `buyer123` |
| 供货商 | `hengxin_wenju`（另 4 家同类） | `supplier123` |

> 初始账号**不强制首次登录改密**。需要强制时，在「系统管理 → 账号管理」建号或重置密码时打开"下次登录须改密"开关。
> 生产环境请立即改管理员密码并关闭 `SEED_DEMO`。

手机端：全站响应式，`<768px` 时左侧菜单收进汉堡按钮；表格在手机上为**表格内部横向滚动**（页面本身不会左右晃）。

## 2. 采购管理 · 报价单

### 2.1 我能做什么

| 操作 | 位置 | 说明 |
|---|---|---|
| 新建报价单 | 列表右上「+ 新建报价单」 | 填项目、截止时间，逐行加物料（名称/规格/单位/数量） |
| Excel 导入明细 | 新建/编辑页里的「Excel 导入」 | 可先下载模板；**单次最多 2000 行**，导入前有预校验（单位必须在字典内），超限请分批 |
| 邀请供货商 | 新建/编辑页选择供货商 | 只有被邀请的供货商能报价 |
| 发布 | 列表行内「发布」 | 发布后才进入供货商"待报价"；**发布后仍可追加供货商**（未截止前） |
| 截止 | 列表行内「截止」 | 到截止时间系统也会自动截止（后台每 60 秒扫描一次） |
| 查看进度 | 列表点单号 / 「查看进度」 | 看到每家供货商是否已报价、报价时间、明细 |
| 导出 | 列表行内「导出」/ 单号详情页 | 导出该询价单及报价结果 `.xlsx` |

### 2.2 单据状态

| 状态 | 含义 | 可做的操作 |
|---|---|---|
| 未发布（草稿） | 还在编辑 | 编辑、删除、发布 |
| 已发布 | 供货商可填报 | 追加供货商、截至前一直可收报价 |
| 已截止 | 不能再改报价 | 比价、导出 |

### 2.3 注意

- 单据号 `RFQ+日期+序号` 由系统按**创建日**生成，不能手填。
- 截止时间统一按**北京时间**（全站时间口径，见第 6 节）。
- 采购员只能看到自己创建的询价单；管理员看全部。

## 3. 采购管理 · 供货商手机端报价

1. 供货商用账号登录 → 看到「待报价 / 已报价」两类单据。
2. 点单据进入填报页 → 逐行填含税单价、税率、交期、备注 → 保存。
3. **可以多次改价**，每次修改都会留下改价历史（列表页可查）。
4. 手机上表单为卡片式布局，数字键盘直接弹起；底部有固定操作栏。
5. 微信内置浏览器里点"导出/下载"会提示用**系统浏览器**打开（微信不允许直接下载文件）。

## 4. 采购管理 · 报价单统计报表

两个视图，切换页签即可：

| 视图 | 用途 | 关键点 |
|---|---|---|
| **比价明细** | 一张询价单里，各供货商逐行对比 | 最低价行有高亮；可按"只看未报价"筛选；可导出 |
| **汇总统计** | 按时间范围汇总所有单据与报价 | 可导出 `.xlsx`；**单次导出上限 5000 行**（`export_max_rows`） |

> 非管理员在页头会看到「统计范围：仅我创建的单据」徽标——这是**服务端强制**的数据隔离，不是前端隐藏。

## 5. 项目管理

项目管理与报价**完全独立**：不共享数据，项目里看到的都是手工维护或从模板复制的内容。

### 5.1 进度看板（`/pm`）

页面自上而下：

1. **指标卡**：项目总数 / 进行中 / 已竣工 / 已超期 / 30 天内到期
2. **阶段分布**：按各项目"当前阶段"计数
3. **近期关键节点**：按计划竣工日期由近到远（超期标红）
4. **多项目进度甘特图**（可折叠，右上「收起/展开」）
   - 横轴按日期：范围自动取所有项目"最早开工 ~ 最晚计划竣工"
   - ≤24 个月按月刻度，超过自动改季度刻度；红色虚线是"今天"
   - 条形颜色：进行中（青绿）/ 已竣工（绿）/ 暂停（橙）/ 超期（红），条内深色部分=总体进度
   - 鼠标悬停看起止日期、阶段、进度、工序完成数、剩余/超期天数
   - **点击条形或项目名**进入该项目的工期计划表
5. **项目清单**：当前阶段、状态、工期、开工/计划竣工、进度条、剩余、**工序 x/y**、项目经理
6. 右上「**导出 Excel**」：导出多项目进度清单

**进度怎么算**：按 `开工日 → 计划竣工日` 的日期跨度自动算百分比，不用手填；"当前阶段"与"状态"才需要手工维护（计划与实际分开表达）。

### 5.2 工期计划表（从看板点项目进入）

- 默认 8 阶段：决策立项 2 → 勘察设计 3 → 招标签约 1.5 → 施工准备 1 → 施工实施 14 → 调试试运行 1.5 → 竣工验收 1 → 缺陷保修 24 月
- 可逐行改：工期、关键交付物、项目经理角色、责任主体；可加行/删行/上移
- 开始月、结束月是"自立项起算的累计月数"，改工期后**自动重算**
- 页头合计口径：**建设工期（1~7）**、**项目经理在场（4~7）**、**含质保合计**
- 「保存阶段表」保存改动；「重置为标准模板」会丢弃改动（二次确认）
- 右上「导出 Excel」导出本表（含合计行）

### 5.3 施工实施步骤（`/pm/processes`）

- 默认显示**某个项目的工序副本**，顶部可切换项目；管理员可切到「标准模板」（只影响以后新建的项目）
- 每行可维护：工序分组、名称、负责人、主要工作内容、质量控制点、紧前工序
- **状态按钮**（按当前状态给动作）：
  - 未开始 → 「开始」
  - 进行中 → 「**更新**」（提交当前进度说明）、「完成」、「暂停」
  - 暂停 → 「恢复」
  - 已完成 → 「重开」
- 「更新」只记录进度说明、**不改变状态**，每次提交都写一条进度历史
- 顶部汇总条：已完成 x/y、进行中/暂停/未开始数量、当前进行中的工序名
- 行内「历史」抽屉：看谁在什么时候把工序推进到哪一步、报了什么进展
- 右上「导出 Excel」导出当前范围（项目副本或标准模板）的工序明细

### 5.4 预算决算管理点（`/pm/cost-points`）

- 默认 14 个控制点（预算编制 3 / 过程管控 4 / 竣工结算 4 / 财务决算 2 / 审计配合 1）
- 同样分「项目副本 / 标准模板」，可增、改、删
- 右上「导出 Excel」

### 5.5 预算决算配套单据（`/pm/documents`）

按你的实际流程，这张表把"单据走到哪一步、归档齐了没"管起来：

| 列 | 怎么用 |
|---|---|
| **核心栏目** | 看这类单据必须有哪些内容 |
| **审批节点** | 显示当前节点与位置 `2/3`；点「选择」可**推进到任一节点，也可退回**（留历史） |
| **归档** | `已归档 x/y`；点「归档」弹窗逐项勾选文件；全部勾完自动记为"已归档"并记录时间/人 |
| **归档要求** | **直接列出要归档的文件名**（✓=已归档 ○=未归档）；超过 3 个显示「+N 个文件（悬停看全部）」；**鼠标悬停**看每个文件的「要求」、状态、归档时间与操作人 |
| **操作** | 编辑 / 历史 / 删除 |

其他能力：

- **多选批量归档**：表格左侧勾选若干行 → 顶部「批量标记已归档 / 撤销归档」；工具条有小计（单据数、已归档单据 x/y、归档文件 x/y）
- **追加归档文件**：在「归档」弹窗底部「+ 追加文件」，追加后该单据回到未完成状态
- **编辑弹窗里定义**：审批流转节点（增删/上移）、归档文件清单（文件名 + 备注）
- 「历史」抽屉区分两类记录：**节点推进**（原节点 → 新节点）与**归档操作**（归档/撤销/批量）
- 右上「导出 Excel」导出当前范围的单据（节点链、归档文件与完成情况）

### 5.6 模板 vs 项目副本（容易误解，重点看）

| | 标准模板 | 项目副本 |
|---|---|---|
| 谁能改 | **仅管理员** | 管理员 + 采购员 |
| 影响范围 | 只影响**以后新建的项目** | 只影响当前项目 |
| 当前节点 / 归档状态 | 不跟踪 | 跟踪 |
| 从模板重置 | — | 子页右上「按模板重置本项目的三项参考表」（会丢弃项目内改动） |

> 新建项目会自动复制模板（15 工序 / 14 管理点 / 12 单据）；老项目首次打开也会自动补齐，**不会覆盖**已有改动。

| 页面 | 能做什么 | 注意 |
|---|---|---|
| **账号管理** | 我方账号 + 供货商账号：新建、编辑、启停用、重置密码、批量导入（可下载模板）、导出清单 | 供货商账号与供货商档案绑定；导出**不含任何密码** |

| **操作日志** | 按时间/操作人/动作类型筛选，导出 CSV | **只读**：任何角色都没有删除入口，系统也不提供删除接口 |

## 7. 通用规则与注意事项

1. **时间口径**：全站北京时间（不换算时区）。在非 UTC+8 的设备上，"截止时刻"文字会偏，倒计时不受影响。
2. **数据隔离**：供货商按登录账号只看到自己的单据；采购员只看到自己创建的询价单与统计——**服务端强制**，不是前端隐藏按钮。
3. **重置操作的代价**：「重置为标准模板」会丢弃该项目的手工修改（节点、归档状态、工序进度都会重置），操作前有二次确认。
4. **归档的两个层次**：文件级（逐个勾）→ 单据级（全部勾完自动完成）；撤销任一文件，单据即回到未完成。
5. **导出范围**：项目管理各页导出的是**当前页面作用域**（选了哪个项目就导哪个；管理员切到标准模板则导模板）；模板导出仅管理员可用。
6. **手机端表格**：宽表格在手机上为表格内部横向滚动，页面不会整体左右晃；甘特图同理（左侧项目名固定）。
7. **操作留痕**：报价改价、工序状态/进度、单据节点/归档、项目与账号增删改，都会写进操作日志或各自的"历史"。

## 8. 常见问题

**Q1：新建了询价单，供货商看不到？**
A：确认已点「发布」。草稿状态供货商看不到；未发布前也不显示在待报价列表。

**Q2：供货商说改不了价？**
A：单据已截止（到点自动截止，或被人点了「截止」）。截止后报价锁定，只能查看历史。

**Q3：采购员登录后找不到「系统管理」？**
A：设计如此——采购员没有系统管理权限，账号、字典、日志只有管理员可见。

**Q4：报表里的数据比预期少？**
A：采购员只能看到自己创建的单据（页头有「统计范围」徽标）。要全部数据请用管理员账号。

**Q5：改了「标准模板」，为什么老项目没变？**
A：模板只决定**以后新建项目**的初始内容，避免覆盖已有项目的改动。要让某个项目同步，在子页点「按模板重置本项目的三项参考表」。

**Q6：工序"更新"和"完成"有什么区别？**
A：「更新」只记录一句进度说明（状态仍是进行中，写一条进度历史）；「完成」才是状态流转，会记实际完成时间。

**Q7：甘特图为什么没有某些项目？**
A：只有同时填写了「开工日期」和「计划竣工日期」的项目才会画条形。去项目编辑里补齐日期即可。

**Q8：归档要求列的文件名太长看不清？**
A：鼠标悬停该单元格，浮窗会列出每个文件的完整名称、要求、归档状态与时间。

**Q9：能拖动甘特图改日期吗？**
A：当前版本**只读**（避免误拖）。改日期请进项目编辑弹窗。

**Q10：手机上能改价格/归档吗？**
A：能，但表格为内部横向滚动，建议优先用电脑维护；字段校验与权限和电脑端一致。
